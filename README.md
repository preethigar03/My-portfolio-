My Portfolio

A personal portfolio website built to showcase my projects, skills, and certifications.

✨ Features

- Responsive design across desktop and mobile
- Projects showcase section
- Skills section
- Certifications section with animated cards

🛠️ Tech Stack

- *Frontend:* React (v19), Vite
- *Styling:* CSS
- *Linting:* ESLint

🚀 Getting Started

Clone the repository and install dependencies:

bash
git clone https://github.com/preethigar03/My-portfolio-.git
cd My-portfolio-
npm install


Run the development server:

bash
npm run dev


Build for production:

bash
npm run build


Preview the production build:

bash
npm run preview
